RAM Concept Share — Package Builder

Build a single password-protected HTML file containing the plans, reports and drawings you want to share. The recipient opens it in any browser. Your .cpt model never leaves your machine unless you choose to include it.

"View only" files are shown inside the viewer but have no download button. The recipient can still take screenshots; nothing can prevent that. Untick download for anything you want to keep as read-only, and only tick it for files you are happy to hand over (for example a DXF background).

3. Password

Use a long passphrase (four or more random words). Send it by a different channel than the file, for example by phone or text message. The password is never stored in the package; there is no recovery if it is lost.

4. Build

  • Encryption: AES-256-GCM, key derived from the password with PBKDF2-SHA256 (600,000 iterations). Everything runs in this browser tab. Nothing is uploaded anywhere.
  • The expiry date is checked by the viewer only. It deters casual use after the date but is not a security control.
